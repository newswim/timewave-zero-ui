# Reference materials

Local study copies supporting the restoration. Provenance:

- `original-c/` — Peter Meyer's timewave calculation code and the four
  384-value data sets, **public domain** (Unlicense), via
  [kl4yfd/timewave_z3r0](https://github.com/kl4yfd/timewave_z3r0).
  This is the ground truth the JS port is validated against.
- `mckenna-derivation-waveexplain.txt` — text of Terence McKenna,
  "Derivation of the Timewave from the King Wen Sequence of Hexagrams"
  (levity.com/eschaton/waveexplain.html), including Table 2.
- `sheliak-1998-decoded.txt` — text of John Sheliak's TWZ formalization
  paper, decoded from a font-obfuscated PDF; imperfect around equations.

The two texts are third-party writings kept here for study; don't
redistribute them as part of any published build of this project — cite
and link instead (see docs/research.md → Sources).
